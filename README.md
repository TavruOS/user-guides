# TavruOS User Guides

Start with an app from the TavruOS application menu. The screenshots show the preview desktop and sample data. Available features depend on your installed app version and configured services.

| What you want to do | Guide |
|---|---|
| Turn a spreadsheet into charts and a dashboard | [Tavru Analytics](analytics.md) |
| Link chart filters, arrange a dashboard, and infer charts or relationships | [Advanced Tavru Analytics](analytics-advanced.md) |
| Build in Tavru Code and run the result with Podman or Docker | [Tavru Code + Tavru Containers](code-and-containers.md) |
| Scaffold a workspace and share reusable snippets | [Tavru Code templates](code-templates.md) |
| Extend a photo and generate content beyond its edges | [Tavru Photo generative expand](photo-advanced.md) |
| Browse files, search for photos and receipts, use the web, or set up email | [Files, Browser, and Mail](apps.md#everyday-apps) |
| Write documents, edit spreadsheets, make slides, or review a PDF | [Documents and presentations](apps.md#documents-and-presentations) |
| Edit photos, generate images, or play music and videos | [Images and media](apps.md#images-and-media) |
| Explore security, the desktop, communication, and games | [System and desktop](apps.md#system-and-desktop) |

For the live image and installation instructions, visit [TavruOS](https://tavruos.com/). Report a documentation problem or request another walkthrough on [TavruOS Feedback](https://github.com/TavruOS/feedback/issues).
